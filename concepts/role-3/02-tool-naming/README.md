A tool name is the first signal Claude reads. If the name does not communicate domain and action clearly, descriptions must compensate — and descriptions are read second, not first. Split tools so names carry signal. Never consolidate when the caller must specify what type of thing to do — that parameter is a split waiting to happen.



A model choosing to verify identity before a financial action is not a naming problem. It is workflow reasoning. The fix is not better naming — it is forcing tool choice at the orchestration level when you need a specific tool to run immediately.
